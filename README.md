# Library Management System (LMS)

A desktop-based Library Management System designed to automate library operations, including book records, member management, issuing, and returning books.

## 🛠️ Main Technologies Used

* **Language:** Java (JDK 8 or higher)
* **IDE:** NetBeans IDE
* **Database:** MySQL
* **GUI Framework:** Java Swing / AWT

## ✨ Key Features

* **User Authentication:** Secure Admin Login System.
* **Book Management:** Add, update, view, and delete book entries.
* **Member Management:** Add and manage student/member information.
* **Issue & Return System:** Issue books to members and track return dates.
* **Search Functionality:** Quick search for books and member records.

## 📦 Dependencies & JAR Files

* **MySQL Connector/J (`mysql-connector-java-8.0.28.jar`):** For connecting the Java application to the MySQL database.
* **JCalendar (`jcalendar-1.4.jar`):** UI component for date selection in issue/return forms.

## 🚀 How to Run Locally

### Prerequisites
